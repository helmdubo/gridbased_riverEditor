# AGENTS.md

Цель: подготовить скелет проекта (Vite + React + TypeScript) и базовый CI.

## Команды
- setup: `./scripts/setup.sh`
- dev:   `./scripts/dev.sh`
- test:  `./scripts/test.sh`

## Инструкции запуска
1. Выполните `./scripts/setup.sh`, чтобы установить зависимости.
2. Запустите локальный сервер командой `./scripts/dev.sh`.
3. Для проверки тестов используйте `./scripts/test.sh`.

Правила: Conventional Commits, не коммитить секреты (.env*).
Готовность: сборка проходит, CI зелёный.
