# Grid-Based River Editor

Интерактивный редактор речных систем на основе сетки с поддержкой притоков и визуализацией потоков воды.

## 🌊 Возможности

- ✅ Создание главной реки с помощью контрольных точек
- ✅ Добавление притоков с настраиваемой шириной
- ✅ Интерполяция кривых (Catmull-Rom сплайны)
- ✅ Визуализация потоков воды с направлением и скоростью
- ✅ Разные типы рек (стоячая вода, равнинная, горная, бурный поток)
- ✅ Marching Squares для отрисовки контуров
- ✅ Snap-to-point и snap-to-spline для притоков
- ✅ Интерактивное перетаскивание точек
- ✅ Защита от неверных топологий (запрещенные зоны вокруг узлов)

## 🏗️ Архитектура

Проект организован по принципу многослойной архитектуры:

```
Domain Layer (модели, константы, утилиты)
    ↓
Service Layer (бизнес-логика)
    ↓
Hooks Layer (React hooks)
    ↓
Presentation Layer (UI компоненты)
```

Подробнее см. [ARCHITECTURE.md](./ARCHITECTURE.md)

## 🎯 Использование

### Базовые операции

1. **Настройка сетки**: При запуске настройте размер сетки (10-40 колонок, 8-30 рядов)

2. **Создание реки**:
   - Кликните на поле для добавления первой точки
   - Выберите крайнюю точку (исток/устье) и кликните снова для продолжения реки

3. **Создание притока**:
   - Выберите внутреннюю точку основной реки
   - Кликните на поле - создастся новый приток

4. **Перемещение точек**:
   - Перетащите любую точку для изменения формы реки
   - При перетаскивании автоматически активируется соответствующий сплайн

5. **Присоединение притока**:
   - К точке: перетащите устье откреплённого притока к точке реки
   - К сплайну: перетащите устье к линии реки (вне запрещённых зон)

6. **Удаление**:
   - Двойной клик по точке удаляет её
   - Удаление узловой точки открепляет приток

### Параметры

- **River Width**: Ширина основной реки (20-150 пикселей)
- **Trib Width**: Ширина притока в % от основной реки (10-100%)
- **River Type**: Тип реки, влияет на скорость потока
- **Curve Weight/Scale**: Параметры влияния кривизны на поток
- **Flow Map**: RGB-визуализация (R=Vx, G=Vy, B=Скорость)
- **Flow Arrows**: Стрелки направления потока
- **Debug Zones**: Визуализация запрещённых зон вокруг узлов

## 📚 Алгоритмы

### 1. Интерполяция кривых
Используется **Catmull-Rom spline** для плавных кривых через контрольные точки.

### 2. Marching Squares
Алгоритм для отрисовки контуров воды/земли на сетке. 16 случаев в зависимости от состояния углов ячейки.

### 3. Расчет потоков
Учитывает:
- Тип реки (базовая скорость)
- Сужение русла (увеличивает скорость)
- Кривизну (внешний поворот быстрее внутреннего)
- Расстояние от центра русла (параболический профиль скорости)

### 4. Снеппинг притоков
- **Point snapping**: привязка к существующим точкам (радиус 25px)
- **Spline snapping**: привязка к линии сплайна (радиус 30px)
- **Forbidden zones**: запрещенные зоны вокруг узлов (радиус = ширина реки)

## 🎨 Цветовая схема

- **Основная река**: Красная (неактивная) / Оранжевая (активная)
- **Приток присоединённый**: Синяя (неактивная) / Голубая (активная)
- **Приток откреплённый**: Оранжевая пунктирная
- **Узловые точки**: Зелёные
- **Выделенные точки**: Жёлтая обводка
- **Snap highlight**: Золотая подсветка
